Chapter 1 · LLM Advanced

Small models learn from a teacher's distribution

Gemma 2 2B, Llama 3.2 1B and 3B, Minitron and the R1 "distill" checkpoints were taught by a bigger model. The teacher sends a score for every token, not one label.

5 sections · needs: softmax and cross-entropy, GPT-2 logits shape (batch, seq_len, vocab), SFT and DPO basics

01Intuition: dark knowledge and soft targets

The small probabilities carry the teacher's knowledge

Hinton, Vinyals and Dean called this extra signal dark knowledge. A student trained on the whole distribution gets more bits per example. It generalizes better and needs fewer examples than one trained on hard labels alone.

One problem: a confident teacher puts almost all mass on the top token, so the small probabilities barely move the gradient. Temperature fixes this. Dividing the logits by T > 1 before the softmax flattens the distribution.

As T grows, both distributions approach uniform. As T shrinks to 0, they approach one-hot on the argmax. At inference the student always runs at T = 1.

02The math of classic knowledge distillation

The T² factor keeps the soft loss the same size at any temperature

Why multiply by T²

White-box versus black-box

The loss needs the teacher's logits and a shared tokenizer, because p and q must live on the same vocabulary. Llama 3.1 8B can teach Llama 3.2 1B this way. GPT-4 cannot teach a Llama model this way.

03Distilling generative models: which KL, and on whose samples

Reverse KL and student-made prefixes remove the blends

A language model defines a distribution over whole sequences, \(p(y \mid x) = \prod_t p(y_t \mid y_{<t}, x)\). That raises two questions classic KD never asked: which KL, and whose samples?

MiniLLM optimizes sequence-level reverse KL. The expectation is over student samples, so it uses a policy-gradient estimator with variance reduction (single-step decomposition, teacher-mixed sampling). The loop looks like RL where the reward is the teacher's log-likelihood. Sequence-level KD (Kim and Rush) instead runs beam search on the teacher and trains on its outputs with plain cross-entropy. That is SFT on synthetic data.

Exposure bias and on-policy distillation

The cost: the teacher must be online during training and share the student's tokenizer, so on-policy distillation is mostly used inside one model family. The Thinking Machines post makes the same point: you get RL's on-policy benefit at a fraction of the sample cost, because each episode gives a gradient per token.

04Code: a token-level KD loss in PyTorch

A correct KD loss gets three details right

The three details most buggy versions miss: the T² factor, masking padding and prompt tokens, and averaging over real tokens instead of the batch dimension.

kd_loss.py
import torch
import torch.nn.functional as F


def kd_loss(
    student_logits: torch.Tensor,   # (B, L, V)
    teacher_logits: torch.Tensor,   # (B, L, V)
    labels: torch.Tensor,           # (B, L), -100 marks positions to ignore
    temperature: float = 2.0,
    alpha: float = 0.5,
    reverse: bool = False,
) -> torch.Tensor:
    mask = labels != -100                             # (B, L)
    s = student_logits.float() / temperature          # fp32: log_softmax over a 128k vocab underflows in bf16
    t = teacher_logits.float().detach() / temperature  # teacher is a fixed target, never trained

    log_q = F.log_softmax(s, dim=-1)
    log_p = F.log_softmax(t, dim=-1)

    if reverse:
        # KL(q || p): penalizes student mass where the teacher has little (mode-seeking)
        kl = (log_q.exp() * (log_q - log_p)).sum(-1)
    else:
        # KL(p || q): penalizes missing teacher mass (mode-covering), Hinton's original choice
        kl = (log_p.exp() * (log_p - log_q)).sum(-1)

    # Mean over real tokens only, so long padded batches do not dilute the signal
    soft = (kl * mask).sum() / mask.sum().clamp(min=1)
    # T^2 keeps the soft-term gradient scale independent of the chosen temperature
    soft = soft * temperature**2

    if alpha >= 1.0:
        return soft
    hard = F.cross_entropy(
        student_logits.float().flatten(0, 1), labels.flatten(), ignore_index=-100
    )
    return alpha * soft + (1 - alpha) * hard

The chapter's self-test checks that identical logits give zero loss and that gradient norms stay in one range as T grows. Without the temperature**2 line they fall about 16× from T = 4 to T = 16.

  • Cache teacher logits as top-k. Full distributions are 128k floats per token. Store the top few dozen to few hundred probabilities per position and renormalize.
  • Check the tokenizer first. Compare teacher_tok.get_vocab() == student_tok.get_vocab() before training, not after a day of it.

The on-policy version reuses the same loss

Only the source of the token sequences changes. Labels mask the prompt, and there are no hard labels, so alpha=1.

on_policy.py
@torch.no_grad()
def sample_on_policy(student, prompt_ids, max_new_tokens=128):
    # The student must see its own mistakes, so prefixes come from student samples
    return student.generate(prompt_ids, do_sample=True, max_new_tokens=max_new_tokens)


def on_policy_step(student, teacher, prompt_ids, optimizer, temperature=1.0):
    seq = sample_on_policy(student, prompt_ids)
    labels = seq.clone()
    labels[:, : prompt_ids.shape[1]] = -100  # only distill the generated part
    with torch.no_grad():
        t_logits = teacher(seq).logits
    s_logits = student(seq).logits
    # alpha=1: no hard labels exist on-policy, the teacher distribution is the only target
    loss = kd_loss(s_logits[:, :-1], t_logits[:, :-1], labels[:, 1:],
                   temperature=temperature, alpha=1.0, reverse=True)
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()

A pair like gpt2-large (teacher) and distilgpt2 (student) shares a tokenizer and runs on a laptop GPU. TRL ships a GKDTrainer with the λ and β knobs.

05Modern practice: where distillation shows up

Most small open models are taught by a bigger one

DistilBERT: the template

Synthetic-data distillation from frontier models

The most common form in 2023 to 2025 is black-box sequence-level KD: a strong model writes responses, a smaller one gets SFT on them.

  • Tulu 3 builds much of its SFT mixture from frontier-model answers (GPT-4o and others) plus persona-driven synthetic prompts. It is forward-KL distillation on sampled text.
  • Llama 3 uses rejection sampling from its own larger models for later SFT rounds. Llama 3.1 405B also improved the post-training data of the 8B and 70B: self-distillation inside a family.
  • DeepSeek-R1 released six R1-Distill models, shown below.

Caveats: black-box distillation inherits the teacher's errors and style, is capped by the teacher on the prompts you chose, and many providers' terms of service restrict it. It also carries no dense per-token signal.

Logit distillation in pretraining

  • Gemma 2 2B and 9B train against a larger teacher's next-token distribution during pretraining, on far more tokens than compute-optimal (the 2B saw 2T). The 27B was trained from scratch.
  • Llama 3.2 1B and 3B were pruned from Llama 3.1 8B, then used logits from Llama 3.1 8B and 70B as token-level targets to recover quality.

This is the most information-dense form, and it needs a large teacher with the same tokenizer.

Pruning plus distillation: Minitron

Importance covers attention heads, MLP neurons, embedding channels and whole layers. Llama-3.1-Minitron 4B applied the same recipe to Llama 3.1 8B, with a short "teacher correction" fine-tune so the teacher matched the distillation corpus.

06Wrap-up

Check the ideas before the project

Common confusions

  • Temperature is applied at inference too.

    T > 1 only softens both distributions inside the training loss. The deployed student runs at T = 1, or whatever sampling temperature you choose, which is unrelated.

  • The T² factor is a magic constant.

    It cancels the 1/T² gradient scaling derived above. Drop it and α silently depends on T.

  • KL and cross-entropy against soft labels give different gradients.

    They differ by the teacher's entropy, constant with respect to the student. The gradients are identical.

  • Fine-tuning on GPT-4 outputs is not distillation.

    It is black-box, sequence-level, forward-KL distillation. It transfers fewer bits per token than logit distillation.

  • Reverse KL is always better for LMs.

    It avoids low-quality blends when the student is much smaller, but it reduces diversity. GKD found the best divergence is task-dependent.

  • On-policy distillation is RL.

    It shares the sampling loop, but the signal is a dense per-token divergence, not a scalar reward. GKD needs no policy-gradient estimator: it differentiates the divergence on fixed samples.

  • Any teacher can teach any student via logits.

    Only with a shared vocabulary. Cross-tokenizer logit distillation is an open research area.

Check yourself

  1. A teacher outputs logits [8, 2, 1]. Compute roughly the teacher distribution at \(T=1\) and \(T=4\). Which teaches the student more about class 2 versus class 3?

    Show answer

    At \(T=1\): \(e^8 \approx 2981\), \(e^2 \approx 7.4\), \(e^1 \approx 2.7\), so about [0.997, 0.0025, 0.0009]. At \(T=4\) the logits become [2, 0.5, 0.25], giving about [0.71, 0.16, 0.13]. The \(T=4\) distribution makes the 2-versus-3 ranking large enough for a meaningful gradient. At \(T=1\) it is buried in the third decimal place.

  2. You double the temperature from 2 to 4 but forget the \(T^2\) factor. What happens to the soft and hard loss balance, and how would you notice?

    Show answer

    The soft-term gradient shrinks by about 4×, so the hard-label term dominates and training behaves more like ordinary SFT. The KD loss plateaus higher and the student's agreement with the teacher's top-k drops, while the hard cross-entropy trains normally.

  3. A 1B student is distilled from a 70B teacher with forward KL on teacher samples. Its outputs are fluent but sometimes mix two unrelated plausible answers. Why, and name two fixes.

    Show answer

    Forward KL is mode-covering: the student is penalized for giving low probability to anything the teacher might say, so a capacity-limited student spreads mass between modes and blends. Switch to reverse KL or \(\mathrm{JSD}_\beta\) with large \(\beta\), and/or train on-policy so the teacher can penalize the student's blended outputs. Sequence-level KD with low-temperature teacher samples also helps by giving one mode per prompt.

  4. Why does GKD sample from the student rather than the teacher, and what extra infrastructure does that need compared with SFT on synthetic data?

    Show answer

    Training on teacher or dataset prefixes leaves a mismatch: at inference the student conditions on its own, possibly wrong, prefixes. Sampling from the student trains on the states it will visit. It needs the student's generation loop inside training and the teacher online to score every generated sequence, typically on a separate inference server or engine.

  5. Why could Llama 3.2 1B use logit distillation from Llama 3.1 70B, while most open models distilled from GPT-4 could not?

    Show answer

    Logit distillation needs both models to output distributions over the same vocabulary. Llama 3.2 and 3.1 share a tokenizer, and Meta owns the 70B weights. GPT-4 is a closed API with a different tokenizer that at most exposes top-k logprobs, so only black-box text distillation is possible.

  6. In Minitron, why distill the pruned model instead of fine-tuning it with ordinary next-token cross-entropy on the same small token budget?

    Show answer

    The pruned model is damaged but still close to the teacher. The teacher's full distribution tells it exactly how to recover the original function, with far more signal per token than one-hot labels. That is how Minitron recovers quality with a tiny fraction of the original token budget.
