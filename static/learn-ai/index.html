Pace

How to use

  1. Read the section notes first. They stand alone.
  2. Run the code yourself. Change a number, predict the result, then check.
  3. Answer "Check yourself" before you open the answers.
  4. Use the Start here resource, then go deeper only where you feel shaky.
  5. Do the chapter project before the next chapter.

Prerequisites

PyTorch

Tensors and shapes, nn.Module, autograd, a training loop. Skip CNNs and deployment.

  • Learn the BasicsStart herePyTorch docs · tutorial · 2 to 3 hours
  • Neural Networks: Zero to HeroAndrej Karpathy · videos 1 to 4
  • Learn PyTorch for Deep LearningDaniel Bourke · online book
  • LLMs-from-scratch, Appendix ASebastian Raschka · code + notes

Python

Functions, classes, lists and dicts, NumPy-style arrays.

  • The Python TutorialStart herePython docs · tutorial
  • NumPy: absolute beginnersNumPy docs · tutorial

Linear algebra

Matrix multiply, dot product, shapes.

  • Essence of Linear AlgebraStart here3Blue1Brown · video series
  • Mathematics for Machine LearningDeisenroth, Faisal, Ong · chapters 2 and 3

Calculus and probability

Gradients, chain rule, softmax, log-likelihood.

  • Neural Networks: Zero to Hero, video 1Start hereAndrej Karpathy · video
  • StatQuestJosh Starmer · video library
  • Mathematics for Machine LearningDeisenroth, Faisal, Ong · chapters 5 and 6
