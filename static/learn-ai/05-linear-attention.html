Chapter 5 · LLM Advanced

Swap the growing cache for a fixed-size state

Softmax attention stays quadratic even with FlashAttention and GQA. Linear attention, SSMs and Mamba change the asymptotics with one idea: a constant-size memory, written and forgotten in different ways.

5 sections · needs: attention, GQA and KV cache, FlashAttention, RoPE, outer products

01Intuition

The softmax blocks the reorder; a feature map removes the block

Causal softmax attention builds an n × n matrix: O(n² d) FLOPs. At inference each new token reads all n cached keys and values. FlashAttention avoids storing that matrix in HBM but still does all the arithmetic.

Matrix products are associative, so (Q Kᵀ) V = Q (Kᵀ V) and Kᵀ V is only d_k × d_v. The softmax applies a nonlinearity to every entry and normalizes each row, so the product no longer factors.

The fix: replace \(\exp(q^\top k)\) with a similarity that factors, \(\mathrm{sim}(q,k) = \phi(q)^\top \phi(k)\). Then the query leaves the sum, and what stays inside is a running state.

Softmax attention keeps every key and value and does exact lookups. Linear attention compresses them into one d_k × d_v matrix. Everything good and bad about these models follows from that compression.

02The math

Causal linear attention is an RNN with a matrix state

Each step writes one outer product, then the query reads the state. With H heads, the whole "KV cache" of a layer is H matrices of size d_k × d_v, at 1k or 1M tokens.

Feature maps decide the similarity

03Code

Three forms of one function agree up to float rounding

linear_attention.py
import torch
import torch.nn.functional as F


def feature_map(x):
    # elu+1 keeps features positive so the normalizer never hits zero or flips sign
    return F.elu(x) + 1


def linear_attn_parallel(q, k, v, eps=1e-6):
    # q, k: (B, H, N, d_k); v: (B, H, N, d_v)
    q, k = feature_map(q), feature_map(k)
    N = q.shape[-2]
    scores = q @ k.transpose(-1, -2)                       # (B, H, N, N), quadratic like softmax attention
    mask = torch.tril(torch.ones(N, N, dtype=torch.bool, device=q.device))
    scores = scores.masked_fill(~mask, 0.0)                # zero, not -inf: there is no softmax to absorb it
    return (scores @ v) / (scores.sum(-1, keepdim=True) + eps)


def linear_attn_recurrent(q, k, v, eps=1e-6):
    q, k = feature_map(q), feature_map(k)
    B, H, N, d_k = q.shape
    d_v = v.shape[-1]
    S = q.new_zeros(B, H, d_k, d_v)   # the whole "KV cache": size independent of N
    z = q.new_zeros(B, H, d_k)        # running sum of keys, for the normalizer
    out = []
    for t in range(N):
        kt, vt, qt = k[:, :, t], v[:, :, t], q[:, :, t]
        S = S + kt.unsqueeze(-1) * vt.unsqueeze(-2)        # rank-1 outer-product write
        z = z + kt
        num = (qt.unsqueeze(-2) @ S).squeeze(-2)            # (B, H, d_v)
        den = (qt * z).sum(-1, keepdim=True)
        out.append(num / (den + eps))
    return torch.stack(out, dim=2)


def linear_attn_chunked(q, k, v, chunk=16, eps=1e-6):
    # Training kernels use this form: matmuls inside a chunk, recurrence across chunks
    q, k = feature_map(q), feature_map(k)
    B, H, N, d_k = q.shape
    d_v = v.shape[-1]
    S = q.new_zeros(B, H, d_k, d_v)
    z = q.new_zeros(B, H, d_k)
    mask = torch.tril(torch.ones(chunk, chunk, dtype=torch.bool, device=q.device))
    out = []
    for s in range(0, N, chunk):
        qc, kc, vc = q[:, :, s:s+chunk], k[:, :, s:s+chunk], v[:, :, s:s+chunk]
        C = qc.shape[-2]
        intra = (qc @ kc.transpose(-1, -2)).masked_fill(~mask[:C, :C], 0.0)
        num = qc @ S + intra @ vc                            # past chunks via state, current chunk via masked scores
        den = (qc @ z.unsqueeze(-1)).squeeze(-1) + intra.sum(-1)
        out.append(num / (den.unsqueeze(-1) + eps))
        S = S + kc.transpose(-1, -2) @ vc
        z = z + kc.sum(-2)
    return torch.cat(out, dim=2)


if __name__ == "__main__":
    torch.manual_seed(0)
    B, H, N, d_k, d_v = 2, 3, 50, 8, 16
    q, k, v = (torch.randn(B, H, N, d) for d in (d_k, d_k, d_v))
    a = linear_attn_parallel(q, k, v)
    b = linear_attn_recurrent(q, k, v)
    c = linear_attn_chunked(q, k, v)
    print("parallel vs recurrent max diff:", (a - b).abs().max().item())
    print("parallel vs chunked   max diff:", (a - c).abs().max().item())
    assert torch.allclose(a, b, atol=1e-5) and torch.allclose(a, c, atol=1e-5)

Zero, not minus infinity, fills the masked scores: there is no softmax to absorb it. Shapes are (batch, heads, seq_len, head_dim).

Add a data-dependent decay

With a per-token scalar \(a_t \in (0,1)\) the state forgets a little before each write. This is the core of RetNet (fixed), Mamba-2 and Gated DeltaNet (learned). The parallel form multiplies the scores by a decay mask \(L\).

decay.py
import torch


def decay_parallel(q, k, v, log_a):
    # log_a: (B, H, N), log of a per-token decay in (0, 1); working in log space avoids underflow of long products
    cum = log_a.cumsum(-1)                                  # (B, H, N)
    N = q.shape[-2]
    L = cum.unsqueeze(-1) - cum.unsqueeze(-2)               # L[i, j] = sum_{j<m<=i} log a_m
    mask = torch.tril(torch.ones(N, N, dtype=torch.bool))
    L = L.masked_fill(~mask, float("-inf")).exp()           # 1-semiseparable decay mask
    return ((q @ k.transpose(-1, -2)) * L) @ v


def decay_recurrent(q, k, v, log_a):
    B, H, N, d_k = q.shape
    S = q.new_zeros(B, H, d_k, v.shape[-1])
    out = []
    for t in range(N):
        a = log_a[:, :, t].exp()[..., None, None]
        S = a * S + k[:, :, t].unsqueeze(-1) * v[:, :, t].unsqueeze(-2)  # forget a little, then write
        out.append((q[:, :, t].unsqueeze(-2) @ S).squeeze(-2))
    return torch.stack(out, dim=2)


if __name__ == "__main__":
    torch.manual_seed(0)
    B, H, N, d_k, d_v = 2, 2, 40, 8, 8
    q, k, v = (torch.randn(B, H, N, d) for d in (d_k, d_k, d_v))
    log_a = torch.nn.functional.logsigmoid(torch.randn(B, H, N) + 2)  # data-dependent gate, mostly near 1
    a, b = decay_parallel(q, k, v, log_a), decay_recurrent(q, k, v, log_a)
    print("max diff:", (a - b).abs().max().item())
    assert torch.allclose(a, b, atol=1e-4)

The mask is built from a cumsum of log gates: each product becomes one subtraction, with no underflow. There is no normalizer; decay models use output normalization instead. In section 04 this script is, almost line for line, Mamba-2.

04Modern family

Each successor changes how the state forgets and how it writes

Plain linear attention only adds. After a few thousand tokens the state is a blurry sum and nothing can be removed. Every successful successor adds a way to forget; the best add a way to overwrite.

RetNet (Sun et al., 2023) uses a different \(\gamma\) per head, so some heads remember long and others short. Its parallel form is \((QK^\top \odot D)V\) with \(D_{ij} = \gamma^{i-j}\): the decay script with constant \(a_t\). It treats parallel, recurrent and chunkwise as a design goal. Weakness: an important token decays as fast as filler.

GLA (Yang et al., 2023) computes \(\alpha_t = \sigma(W_\alpha x_t)^{1/\tau} \in (0,1)^{d_k}\) from the current input, so the model decides token by token what to keep. Its FlashLinearAttention chunkwise kernel made these models fast in wall-clock time, not only asymptotically.

State space models: S4 to Mamba

S4 (Gu et al., 2021) trains as an FFT convolution and infers as a recurrence. Two ingredients made it work: HiPPO initialization of \(A\), derived so that \(h\) optimally compresses the history onto a polynomial basis, and a structured \(A\) that makes \(\bar K\) cheap. It led long-range benchmarks but lagged on language.

Mamba (Gu and Dao, 2023) diagnosed why: S4 is linear time-invariant, so it cannot ignore filler or latch onto a key fact. Mamba makes \(\Delta\), \(B\), \(C\) functions of the input. A large \(\Delta_t\) resets the state toward this token; a small one keeps it.

Losing time-invariance loses the convolution trick, so Mamba computes the recurrence with a hardware-aware parallel scan that keeps the expanded state in SRAM, the FlashAttention lesson again. Mamba-1 was the first attention-free model to match same-size transformers on perplexity at small scale.

Compare Mamba's recurrence with gated linear attention and map \(B_t \leftrightarrow k_t\), \(x_t \leftrightarrow v_t\), \(C_t \leftrightarrow q_t\): the same computation (Fig. 9).

Mamba-2 and state space duality

Restrict \(A\) to a scalar times identity per head, \(\bar A_t = a_t I\). Unrolling gives masked linear attention with \(Q = C\), \(K = B\), \(V = x\) and a decay mask \(L\).

A scalar instead of per-dimension decay lets SSD use matmul chunking (tensor cores) instead of a scan: training 2 to 8 times faster than Mamba-1, with much larger states (\(N = 64\) to \(256\)). Mamba-2 also adds multi-head structure.

RWKV

RWKV (Peng et al., 2023) grew from the attention-free transformer line, with "time mixing" (the token mixer) and "channel mixing" (the MLP). RWKV-4 is a decayed weighted average computable as an RNN. RWKV-5/6 (Eagle, Finch) added matrix states and data-dependent decay; RWKV-7 adopts a generalized delta rule. It scaled to 14B parameters early as a community-trained family.

DeltaNet: overwrite, do not accumulate

Return to the memory view. If the state already holds \(v_{\text{old}}\) under key \(k\), additive writes make a read return roughly \(v_{\text{old}} + v_{\text{new}}\), a corrupted mix. Decay only blurs everything evenly.

The step is one online gradient descent step on \(\tfrac{1}{2}\|S^\top k_t - v_t\|^2\) with learning rate \(\beta_t\). That links the line to test-time training and Titans: the state is a tiny model trained on the context as it streams by. Products of \((I - \beta kk^\top)\) have a compact WY representation, which gives a chunkwise matmul algorithm (Songlin Yang's DeltaNet work).

Gated DeltaNet (Yang, Kautz, Hatamizadeh, 2024) combines both: the gate clears memory at document or topic boundaries, the delta rule edits specific associations. It beats Mamba-2 and DeltaNet on language modeling and retrieval at equal size, and is the linear layer in Qwen3-Next.

05Tradeoffs

A fixed state cannot store everything, so production models are hybrids

This shows up in associative recall: many key-value pairs, then a query key. Zoology (Arora et al., 2023) showed that perplexity gaps between attention-free models and transformers are dominated by tokens that need recall, and grow once the pairs exceed what the state holds. "Repeat After Me" (Jelassi et al., 2024) showed that transformers copy long strings that fixed-state models cannot.

Hybrids: a few attention layers go a long way

  • Jamba (AI21, 2024): 1:7 attention to Mamba, plus mixture-of-experts MLPs. 52B total (12B active), 256k context, about 140k tokens on one 80GB GPU.
  • MiniMax-01 (2025): lightning attention with a softmax layer after every seven. 456B total, multi-million-token contexts.
  • Qwen3-Next (2025): Gated DeltaNet with gated full attention at 3:1.
  • NVIDIA Nemotron-H (2025): mostly Mamba-2 with few attention layers.

Hybrids match or beat pure transformers on standard benchmarks and recover most retrieval. Pure linear models remain mostly a research and edge-device story.

One subtlety: at a few thousand tokens, \(n < d\) for typical models and FlashAttention is extremely optimized, so linear attention may be slower. The win appears at long contexts and, above all, at decode time with large batches, where KV-cache memory is the bottleneck.

06Wrap-up

Check the ideas before the project

Common confusions

  • Linear attention approximates softmax attention.

    Performer tried to. RetNet, Mamba-2 and DeltaNet are different mixers with different inductive biases.

  • Linear means the model is linear.

    Only the recurrence is linear in the state. Projections, input-dependent gates, MLPs and normalization stay nonlinear.

  • The parallel form of linear attention is O(n).

    It is O(n²), same as softmax. Linear cost comes from the recurrent or chunkwise forms.

  • Mamba is not attention.

    Mamba-2's SSD shows it is masked linear attention with a structured decay mask. Mamba-1 differs mainly in per-channel rather than per-head decay.

  • Constant memory means infinite context.

    The state cannot grow, so it cannot hold more. You can process infinite input but not recall arbitrary details from it.

  • Linear models need RoPE.

    Most do not: the decay mask already encodes relative position and recency. Hybrids often use RoPE (or none) in their attention layers only.

Check yourself

  1. Explain with associativity why \(\phi(Q)(\phi(K)^\top V)\) is cheaper than \((\phi(Q)\phi(K)^\top)V\) for long sequences, and why the causal mask blocks the first form in parallel.

    Show answer

    \(\phi(K)^\top V\) is \(d_k \times d_v\) and costs \(O(n d_k d_v)\); multiplying by \(\phi(Q)\) costs the same again, so \(O(n d^2)\) total. The other order builds an \(n \times n\) matrix, \(O(n^2 d)\). With a causal mask, row \(i\) needs a different prefix sum \(\sum_{j \le i} \phi(k_j) v_j^\top\), so one \(\phi(K)^\top V\) is not enough. You need the recurrence (a running sum) or the chunkwise mix.

  2. 32 layers, 32 heads, \(d_k = d_v = 128\), bf16. Compare a pure linear state with a softmax KV cache (no GQA) at 128k tokens.

    Show answer

    Linear: \(32 \times 32 \times 128 \times 128 \times 2\) bytes = 32 MiB, whatever the length. Softmax: \(2 \times 32 \times 32 \times 128 \times 131{,}072 \times 2\) bytes = 64 GiB. A factor of 2048.

  3. Why did input-dependent \(\Delta\), \(B\), \(C\) force Mamba to abandon S4's convolution training?

    Show answer

    The convolution trick needs time invariance: the same \(\bar A, \bar B, C\) at every step give one fixed kernel. With input-dependent parameters each step has different dynamics and there is no single kernel, so Mamba uses a parallel scan of the recurrence.

  4. Write the DeltaNet update for \(\beta_t = 1\) and unit-norm \(k_t\). What does reading the new state with \(k_t\) return, and why can additive attention not do this?

    Show answer

    \(S_t = (I - k_t k_t^\top) S_{t-1} + k_t v_t^\top\). Reading: \(S_t^\top k_t = S_{t-1}^\top (k_t - k_t) + v_t = v_t\). The old association is erased and replaced exactly. Additive attention returns \(S_{t-1}^\top k_t + v_t\): the old value plus the new one.

  5. In decay_parallel, why build the mask from a cumsum of log_a instead of multiplying decays directly?

    Show answer

    Entries are products of up to \(n\) numbers in \((0,1)\), which underflow to zero and are costly to compute pairwise. Prefix sums of logs turn each product into one subtraction, \(\text{cum}_i - \text{cum}_j\). The final exp is stable because masked entries are set to \(-\infty\) first.

  6. A hybrid with one attention layer per eight misses facts in a 200k-token document that a pure transformer finds. Name two architecture-level changes.

    Show answer

    Raise the attention fraction (for example 1:3 instead of 1:7). Enlarge the linear state (more heads, larger \(d_k\), or Mamba-2's larger \(N\)). Switch the linear layers to a delta-rule variant for recall. Make sure the attention layers are full, not sliding-window. Also check that training included long-context retrieval data.

Chapter project

Build an associative-recall benchmark and watch fixed-size states fail

Train four tiny mixers on multi-query associative recall and explain the curves with state-size arithmetic.

  1. Generate an MQAR task: \(P\) random key-value token pairs, then queries of some keys whose target is the matching value. Vary \(P \in \{8, 32, 128, 512\}\).
  2. Implement four 2-layer models that differ only in the token mixer: softmax attention, elu+1 linear attention (section 03), decayed linear attention (decay_parallel with a learned gate), and DeltaNet (recurrent first, chunked optionally).
  3. Train each at head dimensions \(d = 32\) and \(d = 128\), and plot recall accuracy against \(P\).
  4. Explain the curves: at what \(P\) should each model start failing, and does the delta rule beat additive updates at equal state size?
  5. Bonus: add a hybrid (one softmax layer plus one DeltaNet layer) and check if it recovers softmax-level recall. Compare decode speed at 8k tokens between a softmax KV cache and your recurrent DeltaNet.
